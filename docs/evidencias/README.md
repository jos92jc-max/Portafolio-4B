# Evidencias

Esta carpeta contiene las evidencias del proceso de creación del portafolio profesional de Josué Coeto mediante el uso de un agente de desarrollo web.

Las evidencias muestran el trabajo realizado por fases, desde la configuración inicial del agente hasta la revisión final del proyecto.

## Evidencias del proceso

### 01 - Creación del agente
**Archivo:** `01-creacion-agente.png`

Evidencia de la creación y configuración inicial del agente profesional utilizado para apoyar el desarrollo del portafolio.

### 02 - Fase 1: Análisis
**Archivo:** `02-fase-1-analisis.png`

Muestra el análisis inicial del proyecto, la revisión de requerimientos y la identificación de la información necesaria antes de comenzar el desarrollo.

### 03 - Fase 2: Organización
**Archivo:** `03-fase-2-organizacion.png`

Evidencia de la organización de la estructura del proyecto, carpetas, archivos y secciones principales del portafolio.

### 04 - Fase 3: Diseño
**Archivo:** `04-fase-3-diseño.png`

Muestra la propuesta de diseño UX/UI, estructura visual y criterios definidos antes de comenzar la programación.

### 05 - Fase 4: Desarrollo
**Archivo:** `05-fase-4-desarrollo.png`

Evidencia de la implementación del portafolio utilizando HTML5, CSS3 y JavaScript.

### 06 - Resultado del portafolio
**Archivo:** `06-portafolio-final.png`

Muestra el resultado visual del portafolio después de la etapa de desarrollo y las mejoras realizadas.

### 07 - Fase 5: Pruebas
**Archivo:** `07-fase-5-pruebas.png`

Evidencia de las pruebas realizadas sobre navegación, JavaScript, accesibilidad, diseño responsive y funcionamiento general.

### 08 - Fase 6: Corrección
**Archivo:** `08-fase-6-corrección.png`

Muestra la corrección del problema detectado durante las pruebas y la verificación posterior.

### 09 - Fase 7: Documentación
**Archivo:** `09-fase-7-documentacion.png`

Evidencia de la generación y organización de la documentación del proyecto.

### 10 - Fase 8: Entrega y responsive
**Archivo:** `10-fase-8-responsive.png`

Muestra la revisión final del proyecto y su funcionamiento en una resolución móvil de 390 × 844 píxeles.

## Proceso utilizado

El desarrollo se realizó siguiendo el proceso:

**EL ALUMNO DEFINE → EL AGENTE PLANEA → EL AGENTE EJECUTA → EL AGENTE VERIFICA → EL ALUMNO REVISA → SE CORRIGE → SE DOCUMENTA**

Cada fase fue revisada y aprobada antes de continuar con la siguiente.
